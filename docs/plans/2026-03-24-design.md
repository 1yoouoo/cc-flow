# cc-flow Design Document

## Overview

Claude Code 멀티에이전트 실행을 터미널에서 트리 형태로 시각화하는 플러그인.
배치/오케스트레이션 실행 시 어느 에이전트가 언제, 어떤 순서로 실행되는지 한눈에 파악.

## User Experience

# 최초 1회 설정

## Architecture

### Data Flow

```
Claude Code
  └─ PreToolUse (Agent tool)  → hook.js pre  → depth++ → events.jsonl
  └─ PostToolUse (Agent tool) → hook.js post → depth-- → events.jsonl
                                                              ↓
                                                     cc-flow watch
                                                     (fs.watch)
                                                              ↓
                                                       Ink TUI 렌더
```

### Event Format (events.jsonl)

```json
{"type":"start","id":"abc123","name":"idea-picker","depth":2,"ts":1711234567000}
{"type":"end","id":"abc123","depth":2,"ts":1711234568000,"ms":823}
```

### Depth Tracking

- `~/.cc-flow/depth` 파일에 현재 depth 숫자 저장
- PreToolUse: depth 읽기 → 이벤트 기록 → depth+1 저장
- PostToolUse: depth-1 → end 이벤트 기록
- 병렬 에이전트: 같은 depth → 형제 노드로 표시

### Claude Code Hook Config (settings.json)

```json
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "Agent",
      "hooks": [{"type": "command", "command": "node ~/.cc-flow/hook.js pre"}]
    }],
    "PostToolUse": [{
      "matcher": "Agent",
      "hooks": [{"type": "command", "command": "node ~/.cc-flow/hook.js post"}]
    }]
  }
}
```

## Tech Stack

- **Runtime**: Node.js (사용자에게 이미 설치됨)
- **TUI**: Ink (React 모델 TUI)
- **CLI**: Commander.js
- **배포**: npm (`npx cc-flow`)

## File Structure

```
cc-flow/
├── src/
│   ├── cli.js          # commander.js 진입점
│   ├── hook.js         # 훅 스크립트 (stdin → events.jsonl)
│   ├── setup.js        # settings.json 훅 등록
│   └── tui/
│       ├── App.jsx     # Ink 루트 컴포넌트
│       ├── TreeNode.jsx
│       └── ProgressBar.jsx
├── package.json
└── README.md
```

## Edge Cases

| 상황 | 처리 |
|------|------|
| 병렬 에이전트 동시 실행 | 같은 depth → 형제 노드로 표시 |
| watch 안 켠 상태 | events.jsonl에 계속 쌓임, 나중에 켜도 히스토리 보임 |
| Claude Code 비정상 종료 | `cc-flow clear`로 depth 파일 + events 초기화 |
| 중첩 3단계 이상 | 자동 들여쓰기, 제한 없음 |
